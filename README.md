# 🧠 AI Translation Assistant  
### (Kısayol Tabanlı Çeviri Asistanı)
---

## 📌 Proje Amacı

Bu proje, kullanıcıların herhangi bir uygulamada seçtikleri metni **tek tuşla (F8)** yapay zeka kullanarak farklı dillere çeviren bir masaüstü asistanıdır.

### 🎯 Amaç
- Hızlı çeviri sağlamak  
- Manuel kopyala-yapıştır işlemlerini azaltmak  
- Lokal (offline) çalışan bir AI çözümü sunmak

## 🚀 Özellikler

- ✔️ F8 kısayolu ile anında kullanım  
- ✔️ Seçili metni otomatik algılama  
- ✔️ Çoklu dil desteği  
- ✔️ Lokal AI (internet zorunlu değil)  
- ✔️ Popup pencere ile sonuç gösterimi  

---

## 🌍 Desteklenen Diller

- 🇬🇧 İngilizce  
- 🇹🇷 Türkçe  
- 🇩🇪 Almanca  
- 🇫🇷 Fransızca  
- 🇪🇸 İspanyolca  
- 🇷🇺 Rusça  
- 🇯🇵 Japonca  
- 🇸🇦 Arapça  

---

## ⚙️ Nasıl Çalışır?

1. Metni seç  
2. F8 tuşuna bas  
3. Menü açılır  
4. Dil seçilir  
5. AI modeli çeviri üretir  
6. Sonuç ekranda gösterilir  

---

## 🔄 İş Akışı (Workflow)

```
Metin Seç → F8 → Menü Açılır → Dil Seç → AI Model → Çeviri → Sonuç
```

---

## 🧩 Kullanılan Teknolojiler

- Python  
- Ollama (Local LLM)  
- Gemma Model (gemma3:1b)  
- Tkinter (GUI)  
- PyAutoGUI (otomasyon)  
- Pyperclip (clipboard)  
- Pynput (klavye dinleme)  

---

## 🛠️ Kurulum

### 1. Ollama kur
https://ollama.com/download

### 2. Model indir
```bash
ollama run gemma3:1b
```

### 3. Projeyi çalıştır
```bash
BASLAT.bat
```

---

## 🎯 Kullanım

- Metin seç  
- F8 bas  
- Dil seç  
- Çeviriyi gör
